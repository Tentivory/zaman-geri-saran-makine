# ⏰ Zaman Geri Saran Makine

**Dünyanın en ciddi bilimsel projesidir.** 

Bu repository, insanlığın en büyük sorunlarından birini çözmek için kurulmuştur:  
**Zamanın ileriye doğru akması.**

Artık o sorun yok. Bu makine zamanı geri sarıyor.  
Kanıtı mı? Kodu çalıştır. Göreceksin.

## Özellikler

- Zamanı GERÇEKTEN geri sarar (yalan)
- Tembelliği %300 artırır (doğru)
- Çay molası önerir (kesinlikle doğru)
- Hiçbir işe yaramaz (en doğru özellik)
- NASA, CERN ve TÜBİTAK tarafından "yok sayılmıştır" (onlar da anlamamıştır)

## Kurulum

```bash
git clone https://github.com/Tentivory/zaman-geri-saran-makine.git
cd zaman-geri-saran-makine
python3 zaman_geri_sar.py
```

Hepsi bu. Başka bir şey yok. Gerçekten.

## Kullanım

1. Kodu çalıştır.
2. Kaç dakika geri sarmak istediğini yaz.
3. İzle.

5. Tekrar dene. Sonsuza kadar.
